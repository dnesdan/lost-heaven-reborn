# Reconstruction coverage

Evidence labels separate source-data parsing, binary analysis and runtime validation. `PC-FREERIDE-DATA`, `PC-TOMMY-ANIMATION`, `PC-CAR-ASSETS`, `PC-STATIC-CRATE`, and `REA-PC-LS3DF-001` map to private records in the district research evidence index. The REA/Ghidra dossier is static analysis of LS3DF.dll SHA-256 `e211c85009440d6c032f2074d79184f074a9a046574648745c2594b4cef178a6`; REA 6.7.0 at `6d356b84344659085f2b912857b5e27fe0160c9b` with Ghidra 12.1.4. It is not runtime validation. `PS2-CROSSCHECK` remains pending. A parser proves a file can be read, not how the engine uses it. PC behavior is the baseline; PS2 is a platform cross-check.
