# Reconstruction coverage

Status for the Rust rewrite as of 2026-10-21. The 12 rows below preserve the original full-system verification registry: assets and world streaming share one row; audio/UI/localization and save/load have separate rows. A row passes the strict gate only with traceable PC evidence, implementation, and relevant runtime validation; partial parsing, rendering, or a diagnostic probe does not pass it. Phase 1 and phase 2 were accepted by two sequential independent reviewers.

Current validation: `scripts/test.sh` passes 90 Rust tests (52 assets, 16 engine library, 18 application, 4 renderer), 9 REA wrapper tests and 23 progress tests, including formatting, locked workspace checks and Clippy. The prior frozen Linux X11/XTEST captures verify menu navigation, static INTRO, the MISE01 spawn neighborhood with taxi, orbit, repeat-load pixel equality and return to menu. Apple arm64 `cargo check --workspace --all-targets --target aarch64-apple-darwin --locked` passes; this is compilation only, without linking or Metal runtime. Each new clock/Scene/IPol code milestone passed two sequential independent reviews; these isolated library additions have no new gameplay or rendering validation. The application remains a static inspection build: no original cinematic, mission execution, driving or playable campaign.

The strict full-system gate is **0/12**; this is not a remake-completion percentage. Historical private REA/Ghidra retained pseudocode counts are 9/4,914 Game.exe procedures (0.18% of its default inventory) and 45/1,683 LS3DF.dll procedures (2.67% of the documented union profile). They measure retained static inspection, not semantic understanding or implementation. Original PC runtime observations and the narrower PS2 static cross-check are separately indexed in private evidence. Earlier Godot captures/tests and original-game reference play do not count as Rust behavior or validation. See [progress](docs/PROGRESS.md) for milestone history.
