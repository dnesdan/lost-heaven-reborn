Original-code comparison, sampled rendering and gameplay verification remain distinct.

The static inspection route now uses the recovered clock, frame-delta modifier, frame coordinator, empty Scene, shared driver time and model dispatch. The selected Game-loop controller has 123 native comparisons but is not the application's full loop: mission initialization, input helpers and original list population remain open.
