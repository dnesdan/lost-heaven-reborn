Current validation: `scripts/test.sh` passes 188 Rust tests, nine REA wrapper tests and 42 progress tests, plus formatting, locked workspace compilation and Clippy. Linux GPU and X11 checks cover menu navigation, static INTRO/MISE01, camera orbit, repeat-load equality, retained pose upload and bounded position animation. Apple arm64 compilation is checked separately; macOS linking and Metal runtime remain untested. See [progress](docs/PROGRESS.md) for the latest verified run and milestone history.

The static inspection route now uses the recovered clock, frame-delta modifier, frame coordinator, empty Scene, shared driver time and model dispatch. The separate position route also binds the recovered IPol control and position evaluator. Native comparisons cover 22,576 delta cases, 1,509 coordinator cases and six driver edge cases. Seven model-dispatch Rust tests project selected behavior from an 11-case native oracle; they are not a full 11-case state differential. The selected Game-loop controller has 123 native comparisons but is not the application's full loop: mission initialization, input helpers and original list population remain open.

The complete static REA sweeps retain 4,783 Game.exe entries and 1,530 LS3DF.dll entries. Supplied configuration Setup.exe has 172/172 recognized non-thunk procedures retained; the separate installer bootstrap has 376/376. Game entry VA `0x4ab910` fails Ghidra decompilation with “cannot properly adjust input varnodes.” Analyzer inventories include incomplete boundaries, warnings and external/thunk entries; these counts do not establish semantic recovery. Distribution prerequisite installers are separate from game-runtime reconstruction. Frame oracles run unchanged DLL bodies under controlled QEMU/Wine; pure math has additional physical-CPU verification. New PC contracts do not establish PS2 equivalence.

The strict full-system gate remains **0/12**. Static research ratios, reviewed scoped ports and runtime use are separate measures in the [generated dashboard](README.md); no overall completion percentage is claimed. PC evidence is the baseline, with separately indexed PS2 cross-checks and platform differences. Earlier Godot work and original-game reference play do not count as Rust implementation. The campaign, driving and first-mission gameplay are not playable.
