## Retained analysis

The private REA/Ghidra evidence records retained pseudocode for 9/4,914 Game.exe procedures (0.18% of its default inventory) and 45/1,683 LS3DF.dll procedures (2.67% of the documented union profile). These are static inspection counts, not a measure of semantic understanding or implementation. The strict full-system gate remains 0/12 subsystems; no overall remake-completion percentage is defined. A bounded REA/Ghidra contract, `PC-RUST-BOOTSTRAP-001`, confirms selected 4DS header/material and hierarchy behavior, scene-tick structure, and bitmap layout from LS3DF.dll. It does not establish full boot/main-loop behavior, render-pass equivalence, shader or lighting behavior, or PS2 parity. Original PC runtime observations and the narrower PS2 static cross-check are documented separately in private evidence. Keep hashes, addresses, confidence and limitations with those records; public summaries do not replace them.

The dated private mapping `RUST-ENGINE-EVIDENCE-INDEX-20261021` covers the accepted renderer milestone. A separate `RUST-DTA-MILESTONE-EVIDENCE-20261021` snapshot records the DTA reader, REA contract, byte comparisons and image hashes without changing the first snapshot or older progress records. The historical counts remain 9/4,914 and 45/1,683; no new normalized counts are claimed.

Private animation runtime tracing observed 40 animation API time units as 40 milliseconds on one unscaled path. This is a bounded observation, not a universal timing rule for the original engine. Validate each timing path against further static and runtime evidence before implementing it. The first Rust building capture is an approximate rendering proof only; it has no original-render comparison and does not establish visual fidelity.

Earlier Godot captures, parser tests and gameplay checks document the former prototype, not the current Rust application. They may inform future work but do not count toward Rust coverage. See [progress](docs/PROGRESS.md) for the reset boundary and current verification snapshot.
