## Retained analysis

The private REA/Ghidra evidence records retained pseudocode for 9/4,914 Game.exe procedures (0.18% of its default inventory) and 45/1,683 LS3DF.dll procedures (2.67% of the documented union profile). These are static inspection counts, not a measure of semantic understanding or implementation. The strict full-system gate remains 0/12 subsystems; no overall remake-completion percentage is defined. Contracts `PC-RUST-BOOTSTRAP-001`, `PC-RUST-ARCHIVE-001`, `PC-RUST-MENU-001` and `PC-RUST-CONTROL-VM-01` document bounded static findings about selected formats, archive structures, menu dispatch and literal control behavior. They do not establish the full game loop or runtime fidelity. Original PC runtime observations and the narrower PS2 static cross-check are documented separately in private evidence.

Private animation runtime tracing observed 40 animation API time units as 40 milliseconds on one unscaled path. This is a bounded observation, not a universal timing rule for the original engine. Validate each timing path against further static and runtime evidence before implementing it.

Earlier Godot captures, parser tests and gameplay checks are historical evidence only and do not count toward Rust coverage. The original game's verified menu-to-first-mission runtime trace is likewise reference evidence, not a Rust implementation result.
