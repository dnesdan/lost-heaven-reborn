**Base:** `08398317c8dc423d` (pc-Game.exe) · **mafia-re:** `d0fbd6d` · ** CProgram:** `game/mission/C_program.cpp` DecodeParams `CMD_EVENT` 677-708, `CMD_SETEVENT` 1173-1183, execution `CMD_SETEVENT` 3812-3827, `CMD_EVENT_USE_CB` 3828-3835, `C_program::SetEvent` 2763-2792, `C_program::NextCommand` 2660-2685, `C_program::Process` tail `NextCommand(NULL)` 7813 and `CMD_RETURN` 2911-2933; `C_program.h` event ids `EVENT_USE_AB..DETECTOR_HIT` 417-422, `S_event_params` 559-566, `GOSUB_EVENT` 0x8000/`GOSUB_EVENT_TIME` 0x4000/`GOSUB_COMMAND` 0x3fff 429-433, `command_time` 0x24/`event_command_time` 0x28/`event_time` 0x2c/`gosub_stack` 0x30 798-802, `CB_EVENT_BEGIN/END` 686-692.

## Summary

- **Decode:** `EVENT` (73) requires 1–2 words: first word is case-insensitive `use_AB`/`death`/`enemy_to_AI`/`enemy_to_Script`/`hit_from_player`/`detector_hit` → `60000..60005`, otherwise `atoi`, second word optional `atoi` default `0`. `SETEVENT` (74) requires 3 words: `register=atoi`, `event=atoi`, `label` raw unquoted ≤15 bytes. Both use dedicated `EventParameter`/`SetEventParameter` slots with `Allocate/Convert/Release` effects and `HostRuntimeDiscard` counts; empty `SETEVENT` label is admitted as `""` via `b"1,2, \0"` (trailing comma without bytes is not a third param in the extruder). `EVENT_USE_CB` (75) stays scalar (`atoi`).

- **Execution:** `EVENT` has no `Process` case and falls through to `NextCommand(NULL)` → advance (like `LABEL`). `SETEVENT` resolves the actor register (`<0` or out-of-range or empty slot → no actor → advance without effect, no world call); otherwise calls `LookupWorldBackend::set_program_event(actor, event_id)` on the target actor's program. That world call implements `C_program::SetEvent` via `CProgram::try_set_event` returning `SetEventOutcome::{NoEvent,Started,Busy}`: reverse-search for the last `EVENT` with that id, if missing → `NoEvent` (advance); if any `gosub_stack` entry has `GOSUB_EVENT` → `Busy` (jump to `SETEVENT` label, `NextCommand(label)` case-insensitive reverse search, missing label → advance); otherwise `Started` (push `cur_command|0x8000|0x4000`, `cur_command=found`, `event_command_time=command_time`, `event_time=0` (global `GetGameTime` not yet reconstructed), `command_time=0`, and the world sets the target's `state_1c=0` only for `Started`). `EVENT_USE_CB` toggles `0x4000` on `gosub_stack.back()` if non-empty, otherwise advances.

- **Return:** `RETURN` (3) now handles event entries: pop `ret`, `is_event=ret&0x8000`, `back_in_time=ret&0x4000`, `target=ret&0x3fff`, `NextCommand` side-effect (`prev_command=cur`, `command_time=0`, `cur++` then `cur=target`), and if `is_event && back_in_time && !LeaveCompactBlock(false)` restore `command_time=event_command_time` (delta `GetGameTime - event_time` omitted until the `Game` tick loop provides a global clock; `LeaveCompactBlock` searches `BLOCK_BEGIN`/`BLOCK_END` when `in_block` is set, otherwise restores). `CallBack(CB_EVENT_END/BEGIN)` is a no-op (detector base empty, entity stub).

- **World:** `ActorWorld::program_set_event` handles entity and detector programs (other vtables → `Ok(true)`), delegates to `CProgram::try_set_event` and sets `state_1c` only for `SetEventOutcome::Started` (distinguishing `NoEvent` from `Started`). Stale actors propagate; `LookupWorldBackend::set_program_event` (bool `should_advance`) delegates to it. `MissionLookupWorld` and `FakeEntityWorld` implement it.

- **Runtime:** `RuntimeFields` adds `event_command_time`/`event_time` (both `u32`, zero-initialized), `RuntimeView` exposes them, `RuntimeEffect` adds `AllocateEvent/ConvertEventId/ConvertEventExtra/ReleaseEvent` and `AllocateSetEvent/...`, `RuntimeBackend` adds `event_parameter_effect`/`set_event_parameter_effect`, `InstructionParameter` adds `Event`/`SetEvent`, `Compiler` decodes them, `HostRuntimeDiscard` counts `event_allocations`/`set_event_allocations`, `CProgram::try_set_event` returns `SetEventOutcome` and encapsulates the program-local `SetEvent` (search, stack check, push, jump, times), `Process` adds `set_event_payload`, `leave_compact_block` and dispatches 73/74/75 and the event-aware `RETURN` (early return with `NextCommand` side-effects and `LeaveCompactBlock` check).
